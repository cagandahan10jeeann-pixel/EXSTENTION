# 🐾 Python Profile Program

## 📖 Description
This is a simple Python program that displays a personal profile using a function. It prints basic personal information and shows an emoji based on whether the user prefers dogs or cats.

## ✨ Features
- Displays a pet preference using emojis (🐶 or 🐱)
- Shows personal information:
  - Name and Nickname
  - Birthday
  - Address
  - Favorite Song
  - Motivation
  - Support Needed

## 📂 File
- `profile.py` – Main Python program

## ▶️ How to Run

1. Make sure Python is installed.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run:

```bash
python profile.py
```
